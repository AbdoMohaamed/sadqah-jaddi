# موقع صدقة جارية ودعاء لروح فقيدنا الغالي (جدّي رحمه الله) 🌿🤲

موقع إسلامي تفاعلي خفيف وسريع، مبني باستخدام **HTML5, CSS3, JavaScript** ومكتبة **Swiper.js**، ليكون صدقة جارية ودعاء مستمراً لروح الجد رحمه الله وأسكنه فسيح جناته.

---

## ✨ المميزات الرئيسية للموقع:
1. **دعاء رئيسي مخصص:** بطاقة دعاء إسلامية فخمة ومؤثرة لروح الجد.
2. **سلايدر أدعية الزوار (Swiper.js):**
   - عرض أدعية المحبين والزوار بشكل انسيابي وتفاعلي مع إمكانية تحريك السلايدر تلقائياً.
   - زر **"اللهم آمين"** لكل دعاء مع عداد للمؤمّنين.
3. **إمكانية كتابة وإضافة دعاء:**
   - نموذج بسيط يتيح لأي زائر كتابة اسمه ودعائه، أو اختيار أحد الأدعية المأثورة الجاهزة بنقرة واحدة.
   - يظهر الدعاء الجديد فوراً في السلايدر مع حفظه في التخزين المحلي.
4. **سبحة إلكترونية للتسبيح على روحه:**
   - 8 أذكار رئيسية (سبحان الله، الحمد لله، لا إله إلا الله، الله أكبر، استغفار، صلاة على النبي...).
   - عداد تفاعلي مع شريط تقدم دائري، واهتزاز خفيف ونغمات لطيفة تمثل خرزات السبحة.
   - عداد إجمالي لجميع التسبيحات على روحه لتوثيق الأجر المستمر.
5. **قسم آيات وأحاديث:** قبسات من القرآن والسنة عن فضل الاستغفار والدعاء والصدقة الجارية للميت.
6. **مشاركة سهلة ونشر للأجر:**
   - أزرار مباشرة للمشاركة عبر واتساب، تويتر (X)، وزر نسخ الرابط بضغطة زر.
   - تلاوة قرآنية خاشعة هادئة قابلة للتشغيل والإيقاف.

## 🛠️ كيفية تعديل اسم الجد والأدعية بسهولة:
يمكنك تخصيص اسم الجد في سطر واحد فقط:
1. افتح ملف `js/data.js`.
2. في أول سطرين ستجد:
```javascript
const DECEASED_INFO = {
    name: "فقيدنا الغالي (جدّي رحمه الله)", // ضع اسم جدك هنا
    title: "صدقة جارية ودعاء لروحه الطاهرة",
    shortBio: "اللهم اغفر له وارحمه وعافه واعف عنه..."
};
```
3. احفظ الملف وسيتغير الاسم فوراً في كامل صفحات وأزرار الموقع!

## 🚀 طريقة الرفع المجاني على GitHub و GitHub Pages (خطوة بخطوة):

### الطريقة الأولى: عبر سطر الأوامر (Git Terminal) - الأسرع ⚡

1. افتح حسابك على [GitHub](https://github.com/) واضغط على **New Repository**.
2. سمِّ المستودع بأي اسم تريده (مثلاً: `sadqah-jaddi` أو `memorial`).
3. اختر نوع المستودع: **Public**.
4. اضغط **Create repository**.
5. انسخ رابط المستودع الخاص بك (مثل `https://github.com/YourUsername/sadqah-jaddi.git`).
6. في موجه الأوامر (Terminal / PowerShell) داخل مجلد المشروع، نفذ الأوامر التالية:

```bash
git remote add origin https://github.com/YourUsername/sadqah-jaddi.git
git branch -M main
git push -u origin main
```

---

### تفعيل رابط الموقع المجاني (GitHub Pages):
1. داخل صفحة المستودع على GitHub، اضغط على تبويب **Settings** (الإعدادات).
2. من القائمة الجانبية على اليسار، اضغط على **Pages**.
3. تحت قسم **Build and deployment**:
   - في خانة **Branch** اختر `main`.
   - وفي المجلد اختر `/ (root)`.
   - اضغط **Save**.
4. انتظر دقيقة واحدة، ثم أعد تحميل الصفحة، ستجد رابط موقعك المباشر في الأعلى باللون الأخضر:
   `https://YourUsername.github.io/sadqah-jaddi/`

---

### الطريقة الثانية: الرفع اليدوي من المتصفح بدون أوامر 🌐
1. أنشئ مستودعاً جديداً (Public) على GitHub.
2. اضغط على زر **"uploading an existing file"**.
3. اسحب جميع ملفات هذا المجلد (`index.html` ومجلدي `css` و `js`) وأفلتها في المتصفح.
4. اضغط **Commit changes**.
5. اذهب إلى **Settings** -> **Pages** واختر الفرع `main` ثم **Save**.
